# 3D Level 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Level 0 을 three.js 1인칭 3D 로 플레이할 수 있게 한다. 서버와 프로토콜은 그대로 두고, 다른 레벨은 기존 2D 로 플레이한다.

**Architecture:**
- 게임 화면은 캔버스 두 장을 겹친다.
  - 아래: 새 WebGL 캔버스. `Renderer3D` 가 그린다.
  - 위: 기존 2D 캔버스. HUD·사망 연출·점프스케어·시네마틱 같은 화면 고정 그림만 그리는 오버레이가 된다.
- 엔진은 매 프레임 `shouldUse3D()` 로 어느 렌더러를 쓸지 고른다.
- 1인칭 이동은 기존 `updateLocalPlayer` 에 `firstPerson` 옵션을 더해서 만든다. 그래서 서버에 보내는 x, y, angle 은 지금과 같은 px·라디안이다.

**Tech Stack:** three.js `0.170.0` (고정), Next.js 15, React 19, socket.io, 기존 Web Audio `Sound`/`Voice`.

**Spec:** `docs/superpowers/specs/2026-11-19-3d-level0-design.md`

## Global Constraints

- 브랜치 `3d` 에서만 작업하고 커밋한다.
- 의존성은 `three@0.170.0` 하나만 추가한다. 후처리는 `three/examples/jsm/...` 에서 가져온다.
- `server/`, `shared/` 의 판정·AI·맵 생성은 바꾸지 않는다. 기존 `npm test` 가 그대로 통과해야 한다.
- 크기: `PX_PER_M = 32` (타일 48px = 1.5m), 천장 2.7m, 눈높이 1.6m(서기) / 1.0m(웅크리기). 이 상수들은 `game/client/three/units.js` 에만 둔다.
- 3D 의 yaw 는 `p.angle` 과 같은 값이다(2D 기준 atan2(dy, dx), y 아래 방향). pitch 는 클라이언트 전용이고 ±80° 로 제한한다.
- Level 0(`levelIndex === 0`) + 설정 `threeD !== false` + WebGL 사용 가능일 때만 3D. 그 밖은 기존 2D.
- 메뉴·대기방·엔딩·오프닝·사망 연출·점프스케어·HUD 는 기존 2D 코드를 재사용한다. 점프스케어를 3D 쪽에서 따로 띄우지 않는다(사망 연출 lunge 단계에 이미 있다).
- 외부 모델·텍스처 파일은 쓰지 않는다. 텍스처는 캔버스로, 모델은 three 기본 도형으로 만든다.
- 코드 주석·화면 문자열은 한국어로 쓴다. 새 화면 문자열은 `shared/lang/en-ui.js` 또는 `en-client.js` 에 영어를 넣는다.
- 품질 단계: `low` / `medium` / `high`. 기본 `medium`, 터치 기기는 `low`. 목표: `low` 에서 내장 그래픽 노트북 30fps 이상.

## Review Focus

1. **포인터 잠금 중 ESC**: 브라우저는 잠금을 푸는 첫 ESC 를 keydown 으로 주지 않는다. 플레이 중 잠금이 풀리면(ESC, Alt+Tab) 일시정지 메뉴가 열려야 한다. 메뉴를 닫고 캔버스를 클릭하면 다시 잠긴다. → Task 2 에서 `pointerlockchange` 로 처리하고 수동 확인
2. **WebGL 을 쓸 수 없거나 컨텍스트를 잃었을 때**: 하얀 화면이나 멈춤 없이 2D 로 자동으로 돌아가야 한다. → Task 3 에서 `shouldUse3D` 의 `webgl` 인자 테스트, `webglcontextlost` 처리
3. **레벨 전환**: Level 0 → 1(2D) → 전멸 후 다시 Level 0 / 새 게임으로 다시 Level 0 에서 캔버스가 제대로 바뀌어야 한다. 포인터 잠금이 풀리고, GPU 자원이 해제되고, 두 번째 Level 0 도 정상이어야 한다. → Task 3 에서 `setLevel` 이 이전 자원을 `dispose` 하는지 수동 확인
4. **죽은 뒤 관전 / 숨기**: 카메라가 관전 대상의 눈높이와 방향을 따라가야 한다. 사물함 안에서는 사물함 시점 오버레이가 나와야 한다. → Task 3·7 수동 확인
5. **창 크기 변경·고해상도 화면**: 늘어나거나 흐려지지 않아야 한다. 픽셀 비율은 품질별 상한(low 1, medium 1.5, high 2)을 넘지 않는다. → Task 3 `resize()`

- Produces (`game/client/three/units.js`, 순수 함수, three 를 import 하지 않음):
  - `PX_PER_M = 32`, `CEIL_H = 2.7`, `EYE_H = 1.6`, `EYE_CROUCH = 1.0`, `PITCH_MAX = 80 * Math.PI / 180`
  - `toM(px: number): number` — px / 32
  - `yawFromAngle(angle: number): number` — three 카메라 `rotation.y` (order `'YXZ'`). 그 yaw 의 앞 방향 `(-sin y, 0, -cos y)` 이 `(cos angle, 0, sin angle)` 과 같아야 한다 → `-angle - Math.PI / 2`
  - `fpMoveVector(ix: number, iy: number, angle: number): { x: number, y: number }` — 입력(ix: A=-1/D=+1, iy: W=-1/S=+1)을 바라보는 방향 기준 2D px 방향으로 돌린다. 길이는 입력 길이 그대로
  - `facingPan(dx: number, dy: number, angle: number): number` — 소리 나는 쪽이 바라보는 방향의 오른쪽이면 +, 왼쪽이면 −. 범위 −1..1 (`sin(atan2(dy,dx) - angle)`)
  - `shouldUse3D(levelIndex: number, settings: object, webgl: boolean): boolean`

- [ ] **Step 1: `test/three.mjs` 에 실패하는 테스트를 쓴다** (기존 테스트 파일처럼 `check(cond, label)` 형식, 끝에 `ALL PASSED` / 실패 시 `process.exitCode = 1`)

```js
check(toM(48) === 1.5, '타일 48px = 1.5m');
const fwd = a => { const y = yawFromAngle(a); return [-Math.sin(y), -Math.cos(y)]; };
for (const a of [0, Math.PI / 2, Math.PI, -Math.PI / 2, 1]) { const [x, z] = fwd(a); check(Math.abs(x - Math.cos(a)) < 1e-9 && Math.abs(z - Math.sin(a)) < 1e-9, `yaw 앞 방향 = angle 방향 (${a})`); }
let v = fpMoveVector(0, -1, 0); check(Math.abs(v.x - 1) < 1e-9 && Math.abs(v.y) < 1e-9, 'W, angle 0 → +x');
v = fpMoveVector(0, -1, Math.PI / 2); check(Math.abs(v.x) < 1e-9 && Math.abs(v.y - 1) < 1e-9, 'W, angle π/2 → +y (화면 아래)');
v = fpMoveVector(1, 0, 0); check(Math.abs(v.x) < 1e-9 && Math.abs(v.y - 1) < 1e-9, 'D, angle 0 → 오른쪽(+y)');
v = fpMoveVector(0, 1, 0); check(Math.abs(v.x + 1) < 1e-9, 'S → 뒤로');
check(facingPan(0, 10, 0) > 0.99 && facingPan(0, -10, 0) < -0.99 && Math.abs(facingPan(10, 0, 0)) < 1e-9, 'facingPan: 오른쪽 +, 왼쪽 −, 정면 0');
check(shouldUse3D(0, {}, true) && !shouldUse3D(1, {}, true) && !shouldUse3D(0, { threeD: false }, true) && !shouldUse3D(0, {}, false), 'shouldUse3D: Level 0 + 설정 켜짐 + WebGL 일 때만');
```
